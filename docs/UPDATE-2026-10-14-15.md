## Deployment lokal dan perbaikan error

Repositori dipasang pada XAMPP PHP 8.2 dan MariaDB. Dependency runtime dipasang menggunakan composer install --no-dev karena Pint pada lock file memerlukan PHP 8.3. Frontend dibangun dengan npm/Vite, APP_KEY dibuat lokal, migration/seeder dijalankan, dan public/storage dihubungkan ke disk public.

Error 500 pada detail komoditas disebabkan kurung penutup match yang hilang dalam template. Sintaks tersebut diperbaiki. URL navigasi, form, ilustrasi, foto, dan preview upload yang sebelumnya mengarah ke root localhost diperbaiki untuk deployment dalam subfolder. Action form tambah/edit admin diperbaiki agar menunjuk record yang benar.

Konfigurasi URL disk public mengikuti APP_URL. Template upload memakai disk public secara eksplisit. Root .htaccess mengarahkan folder aplikasi ke public/ dan menolak akses langsung file source, .env, dan .git. Pada hosting, tetap gunakan document root public/.

## Galeri dan upload

Komoditas dan produk olahan memakai lima slot seragam:

| Slot | Field database | Pemakaian |
|---|---|---|
| Foto Utama | image_path | Kartu katalog dan foto pertama detail |
| Foto 2 | image_path_2 | Thumbnail/detail |
| Foto 3 | image_path_3 | Thumbnail/detail |
| Foto 4 | image_path_4 | Thumbnail/detail |
| Foto 5 | image_path_5 | Thumbnail/detail |

Migration 2026_10_14_160000_add_catalog_photo_slots menambah field tersebut. Model, validasi, controller, form admin, dan template diperbarui. File disimpan pada disk public; database menyimpan path. Maksimum per file 4 MB, dengan format JPG/JPEG/PNG/WebP. Slot kosong mempertahankan foto lama. Foto pengganti disimpan sebelum perubahan database, file baru dibersihkan bila transaksi gagal, dan file lama dibuang setelah transaksi sukses.

Seluruh **27 record katalog** mempunyai dua foto awal, total 54 slot terisi. Slot 3–5 tersedia untuk upload tambahan. Thumbnail mengganti gambar besar, alt text, dan aria-pressed; nomor slot mengikuti field meskipun ada celah slot kosong. Belum ditambahkan fitur drag-reorder atau tombol hapus foto terpisah.

Foto monitoring publik kini menunjuk endpoint foto dan memfilter is_public. Pemeriksaan status KWT pada endpoint diganti ke is_active sesuai schema. Foto monitoring/panen tetap dipisahkan dari galeri katalog, dengan aturan akses masing-masing.

## Deskripsi akhir

Seluruh 12 komoditas dan 15 produk olahan memiliki deskripsi unik dua paragraf, sekitar 500–570 karakter. Copy menonjolkan karakter rasa/tekstur, ide olahan, cara penyajian, dan informasi pemesanan. Kata contoh/demo dihapus dari deskripsi yang tampil. Tidak ditambahkan klaim organik, sertifikasi, manfaat medis, atau masa simpan.

CatalogCopy menyimpan copy terpusat; CatalogDescriptions menjadi akses bersama. Seeder produk dan komoditas menggunakan copy yang sama. CatalogDescriptionsSeeder memperbarui isi database lama tanpa mengganti foto, harga, atau stok.
